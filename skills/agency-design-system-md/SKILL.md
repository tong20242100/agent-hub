# 🎨 Design System MD: 视觉灵魂中心

## 🎯 核心使命
作为 Agent 的“审美大脑”，提供全球顶级品牌的视觉基因组，确保前端产出具有生产级美感。

## 🛠️ 操作流程
1. **查阅清单**: 运行 `get_brand_design(brand="--list")` 了解当前支持范围。
2. **提取气质**: 获取特定品牌的 `DESIGN.md`，理解其 Atmosphere 和 Typography 规则。
3. **注入代码**: 将提取的色值、间距、圆角规则注入到 HTML/CSS 实现中。
